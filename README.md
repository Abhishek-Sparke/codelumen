# CodeSpark ⚡

Deliberate practice and interactive coding mastery platform.

## Overview
CodeSpark is designed for deliberate, feedback-driven engineering practice. It replaces passive tutorial consumption with real-time feedback, algorithmic archetype tracking, curated curriculum roadmaps, and competitive sprints.

## Tech Stack
- **Frontend**: React 19, TypeScript, Vite, TailwindCSS v4
- **Icons**: Lucide React
- **Animations / FX**: Canvas Confetti, custom CSS glow & glassmorphism

## Getting Started
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
